# SEO Seller

SEO Seller пишет текст карточки под конкретную площадку: Wildberries, Ozon или Авито. Вы выбираете витрину, коротко описываете товар — бот собирает заголовок, описание, теги и характеристики.

В кабинет маркетплейса он ничего не загружает. Это черновик, который можно сразу вставить в карточку.

## Для чего

Площадки считают карточку по-разному. Wildberries обрезает название на 60 символах. Ozon почти не ищет по описанию — там важнее заголовок, теги и характеристики. На Авито в ленте видны первые строки объявления.

SEO Seller знает эти ограничения и пишет под выбранную витрину. Без общих фраз вроде «лучший» и «уникальный», без выдуманного состава и без формулировок, которые площадка может отклонить.

Оплаты и личного кабинета нет. Бот не заменяет менеджера карточек — он экономит время на первом тексте.

## Как пользоваться

1. Откройте бота и отправьте `/start`.
2. Выберите площадку: Wildberries, Ozon или Авито.
3. Пришлите фото или сразу факты: что это, бренд, материал, цвет, для кого, по какому поводу покупают. Фото не обязательно — есть кнопка «Без фото».
4. Подождите ответ. Обычно это несколько секунд, иногда около минуты.
5. Скопируйте поля в карточку. Другой вариант формулировок — «Перегенерировать». Тот же товар под другую площадку — «Другая площадка». Следующий товар — «Новый товар».

Чем точнее факты, тем спокойнее текст. Если размера, состава или бренда во вводе нет, бот их не придумает.

## Что приходит в ответ

- **Заголовок** — укладывается в лимит площадки, главный запрос стоит в начале.
- **Описание** — для покупателя: что это, кому подойдёт, как пользоваться, как ухаживать.
- **Теги** — фразы, по которым товар ищут и фильтруют.
- **Характеристики** — короткие значения: пол, материал, крой, цвет, повод.

Можно скопировать заголовок, описание, теги или весь пакет. Если поле не помещается в кнопку Telegram, бот пришлёт его отдельным сообщением.

## Структура проекта

Рабочий код — в `src/marketplace_poster/`. Диалог хранится в памяти: после перезапуска незавершённый разговор сбрасывается.

| Путь | Что внутри |
|---|---|
| `bot/` | Разговор в Telegram: выбор площадки, сбор фактов и фото, кнопки, готовый пакет |
| `platforms/` | Правила Wildberries, Ozon и Авито: лимиты, запрещённые слова, как собирать название |
| `llm/` | Запрос к модели, промпты, разбор ответа |
| `services/` | Сборка текста, проверка лимитов, подсказки по поводам |
| `models/` | Ввод селлера и готовый пакет |
| `config.py` | Настройки из `.env` |
| `preview.py` | Пример карточки без Telegram |
| `tests/` | Автопроверки правил и разбора ответа |

Схема такая: сообщение в Telegram → сбор фактов → правила площадки и модель → проверка лимитов → пакет с кнопками.

## Правила площадок

| | Wildberries | Ozon | Авито |
|---|---|---|---|
| Название | до 60 символов | до 200 | до 50 |
| Описание | до 2000, комфортный объём 800–1500 | до 6000, комфортный объём 1200–2500 | до 7500, комфортный объём 800–1500 |
| Теги | 8–20 | 10–25 | 5–10 |
| На что смотреть | бренд в название лучше не дублировать | описание в поиске почти не участвует | смысл объявления — в первых 200 символах, без `#` |

После модели текст ещё раз проходит проверку: лишняя длина обрезается, эмодзи, ссылки и капслок убираются. Если черновик сильно вылез за лимит или задел запрещённые слова площадки, модель переписывает пакет ещё раз.

## Как устроена генерация

Модель получает правила площадки и факты о товаре. Ответ всегда в одном формате:

```json
{
  "title": "string",
  "description": "string",
  "tags": ["string"],
  "attributes": ["string"]
}
```

Фото, если вы его прислали, скачивается из Telegram только на время запроса и сразу отбрасывается. На диск история генераций не пишется.

Если сменить площадку, бот берёт те же факты и то же фото — заново описывать товар не нужно.

## Модель и настройки

По умолчанию бот использует бесплатный шлюз [Pollinations](https://text.pollinations.ai/openai). Это демо-мера: так проще показать, как устроена система, без отдельного ключа и оплаты. В рабочем контуре планируется более сильная модель.

В запросе модель называется `openai` — это имя на стороне шлюза, не подписка ChatGPT. Качество и скорость могут меняться: провайдер вправе подменить модель за алиасом.

В коде есть запасные варианты: OpenRouter, Ollama, Gemini, Groq, Hugging Face. Их переключают в `.env` через `LLM_PROVIDER` и `LLM_API_KEY`, при необходимости — `LLM_MODEL` и `LLM_BASE_URL`. Ожидание ответа — `LLM_TIMEOUT_S`, по умолчанию 90 секунд.

## Проверки в репозитории

```powershell
python -m pytest
python -m marketplace_poster.preview
```

`pytest` проверяет лимиты площадок и то, как разбирается ответ модели. `preview` печатает эталонный текст худи сразу на три площадки — без живого запроса в нейросеть. Прогон с настоящей моделью: `python -m pytest -m integration`.
